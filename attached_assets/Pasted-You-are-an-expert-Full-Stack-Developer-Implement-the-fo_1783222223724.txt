## Existing Workflow
- The software fetches fault data from Loconet.
- It displays the fetched data in the application.
- It automatically sends Critical Fault notifications through WhatsApp.
- Keep all of the above functionality exactly as it is.

## New Feature Requirements

### 1. Excel-Based Fault Master
Create a Fault Master system that reads an Excel file (.xlsx/.xls).

The Excel file will contain at least the following columns:

- Fault Code
- Fault Description
- Rectification Process

The Rectification Process column may contain long multi-line text, numbered steps, bullet points, and special characters. Preserve the formatting while reading and sending it.

---

### 2. Automatic Fault Code Matching

Whenever new data is received from Loconet:

- Continue displaying data exactly as before.
- Detect every new Critical Fault.
- Extract the Fault Code.
- Search the uploaded Excel Fault Master for the same Fault Code.

If a matching Fault Code exists:

Retrieve:
- Fault Code
- Fault Description
- Complete Rectification Process

If no matching record exists:

Continue sending the normal WhatsApp notification without the rectification details.

---

### 3. Enhanced WhatsApp Notification

When a matching Fault Code is found, automatically send a WhatsApp message in the following format:

🚨 CRITICAL FAULT DETECTED

Loco No:
Date:
Time:

Fault Code:
Fault Description:

=========================
RECTIFICATION PROCESS
=========================

<Complete Rectification Process from Excel>

=========================

Please attend immediately.

The Rectification Process must be sent completely without truncating the text.
